# 「科普」宝宝枕秃是缺钙吗？

> 更新时间：2026-09-17 (UTC+8)

日常生活中不时遇到家长朋友问：“大夫，你看我家宝宝的枕秃，是不是缺钙啊？”，有的家长则问：“医生，我家宝宝夜里总是啼哭，怎么办？”，更有家长问到：“先生，我家宝宝胸前高出一块，是咋回事儿？”，像以上这几种情况，宝宝可能是得了“维生素D缺乏性佝偻病”，下面由漯河市中心医院儿科万玉副主任医师给家长朋友讲解一下“维生素D缺乏性佝偻病”（以下简称佝偻病）。

**一、什么是佝偻病？**

维生素D缺乏性佝偻病是由于儿童体内维生素D不足，导致钙、磷代谢紊乱，引起骨骼钙化障碍的一种慢性营养缺乏病。多见于3个月至2岁婴幼儿，北方发病率高于南方，冬春季高发。虽然很少直接危及生命，但会影响小儿生长发育，重症者可导致骨骼畸形，降低患儿免疫力，易并发肺炎、腹泻等疾病。

**二、常见症状有哪些？**

 

1. 临床分期

初期：3个月左右起病，神经精神症状为主：易激惹、烦躁、睡眠不安、夜啼、多汗（与室温无关）、枕秃；

激期：7-8月至2岁，骨骼改变+运动发育迟缓；

恢复期：治疗后症状减轻，血钙磷回升，骨骼X线改善；

后遗症期：3岁以后无活动性症状，遗留骨骼畸形。

2. 典型骨骼改变

头部

颅骨软化：3-6个月婴儿，按压顶骨/枕骨中央有"乒乓球样"弹性感；

方颅：7-8个月后，额骨和顶骨双侧骨样组织增生隆起，呈方形头型；

前囟异常：前囟增大（>2.5cm）、闭合延迟（>18个月）；

出牙延迟：1岁未出牙，3岁未出齐，牙齿排列不齐、釉质发育不良。

胸部

肋骨串珠：肋骨与肋软骨交界处膨大如串珠（第7-10肋最明显）；

肋膈沟：膈肌附着处肋骨内陷形成横沟（郝氏沟）；

鸡胸/漏斗胸：胸骨向前突出或向内凹陷，影响呼吸功能；

四肢

手镯/脚镯征：腕、踝部骨骺膨大，形成环状隆起；

下肢畸形：1岁后站立行走者出现"O"型腿（膝内翻）或"X"型腿（膝外翻），膝关节间距>3cm。

**三、儿童为什么易患佝偻病？**

1. 围生期维生素D不足：母亲妊娠期，特别是妊娠后期维生素D营养不足，如母亲严重营养不良、肝肾疾病、慢性腹泻、早产、双胎等；

2. 日照不足：户外活动减少、高楼遮挡阳光、冬季日照时间短、婴儿衣物包裹严密等；

3. 生长速度过快：早产儿、双胞胎出生后生长迅速，且维生素D储备不足；婴儿早期生长发育快，需求量大；

4. 食物中补充维生素D不足：天然食物中维生素D含量普遍较低，即使纯母乳喂养，婴儿若户外活动较少，亦易患佝偻病；

5. 疾病影响：胃肠道疾病或肝胆疾病影响维生素D的吸收，如婴儿肝炎综合征、慢性腹泻等。
**四、如何诊断佝偻病？**

1. 病史：日光照射不足、维生素D摄入不足、早产/双胎等高危因素；

2. 典型临床表现：典型骨骼改变、神经精神症状；

3. 实验室检查：血钙正常或降低，血磷明显降低，血清碱性磷酸酶增高，1，25-(OH)D3水平降低为最可靠的诊断标准；
**五、如何治疗佝偻病？**

1.补充维生素D3

口服疗法：一般剂量为2000-3000IU/日，连服1个月后改为预防量（小于1岁婴儿400IU/日，大于1岁婴儿600IU/日），直到2-3岁。

突击疗法（重症/无法口服者）：肌肉注射维生素D3  20万-30万IU/次，1-2次，随后改为预防量；

2.补充钙剂：主张从膳食的牛奶、配方奶和豆制品中补充钙、磷；仅在低血钙表现、严重佝偻病和营养不良时需要补充钙剂。

3.矫形治疗：轻度畸形：加强体格锻炼，如扩胸运动矫正鸡胸，按摩肌群矫正腿型；严重畸形：3岁后骨骼畸形者，可考虑外科手术矫治。
**六、如何预防佝偻病？**

1. 围生期预防：孕妇多晒太阳；妊娠后期补充维生素D3  800IU/日；摄入富含钙、磷的食物（牛奶、鱼类、蛋黄）；

2. 婴幼儿期预防：晒太阳：生后1个月开始，每日户外活动1小时，仅裸露头面部、手足即可；维生素D3补充：足月儿：生后2周开始，每日400IU；早产儿/低体重儿：生后1周开始，每日800IU，3个月后改为400IU，直到2-3岁。

3. 合理喂养：坚持纯母乳喂养至6个月，及时添加辅食；补充富含维生素D的食物：肝类、蛋黄、鱼类等；

4. 特殊人群管理：慢性腹泻/肝胆疾病患儿：调整维生素D剂型和剂量；长期用药儿童：监测维生素D水平，必要时额外补充；

5. 正规治疗1个月后应复查治疗效果，如临床表现、血生化与骨骼X线改变无恢复征象，应进一步查找原因。
